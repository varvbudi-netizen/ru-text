# ru-text — русский текст без потери смысла

Навык для вычитки и редактуры русского текста в Кодексе, Claude Code и других агентах, поддерживающих папку с `SKILL.md`.

Это объединённая и переработанная редакция на основе четырёх открытых источников. Она сохраняет факты, оговорки и голос автора, выбирает глубину правки по запросу и допускает ответ без изменений, когда текст уже хороший. Лицензия — [MIT](LICENSE); авторы и исходные проекты — в [уведомлениях](THIRD_PARTY_NOTICES.md).

## Что умеет

- Исправлять конкретную опечатку без переписывания соседних предложений.
- Вычитывать орфографию, грамматику и пунктуацию.
- Улучшать ясность, связность и лексику в пределах поручения.
- Убирать пустые и неестественные обороты с сохранением авторской манеры.
- Работать с письмами, статьями, документацией и текстами интерфейса.
- Оценивать качество по пяти направлениям, когда пользователь прямо просит оценку.

Обычное «проверь текст» означает вычитку. Оно не разрешает выставлять баллы, переписывать стиль или сохранять изменения в файлах. Числа, имена, цитаты, ссылки, отрицания, степень уверенности и обещания защищены от незаметной подмены.

Навык не определяет машинное авторство и не обещает обход детекторов. Сам русский язык сообщения не запускает полную редактуру ответа.

## Установка

Через каталог Agent Skills, если у тебя установлен Node.js:

```sh
npx skills add varvbudi-netizen/ru-text --skill ru-text
```

Либо скопируй репозиторий целиком в свободную папку навыка. Примеры для Windows и PowerShell:

Кодекс:

```powershell
git clone https://github.com/varvbudi-netizen/ru-text.git "$env:USERPROFILE\.codex\skills\ru-text"
```

Claude Code:

```powershell
git clone https://github.com/varvbudi-netizen/ru-text.git "$env:USERPROFILE\.claude\skills\ru-text"
```

Для других систем обычные места — `~/.codex/skills/ru-text` и `~/.claude/skills/ru-text`. Копируй также `references/`, `licenses/`, `LICENSE` и `THIRD_PARTY_NOTICES.md`: это необходимые справочники и уведомления. После установки обнови список навыков или начни новый сеанс агента.

## Как пользоваться

```text
Используй ru-text. Исправь только ошибки, сохрани мой тон:
[текст]
```

```text
Используй ru-text. Сделай письмо понятнее и короче.
Не меняй факты, сроки и степень вежливости:
[текст]
```

```text
Используй ru-text. Покажи проблемы и предложи правки,
но не изменяй файл.
```

Список режимов и границ — в [SKILL.md](SKILL.md). Справочники загружаются по задаче: одна опечатка не требует чтения всего набора.

## Происхождение и изменения

Использованы [talkstream/ru-text](https://github.com/talkstream/ru-text), [miolamio/agent-skills](https://github.com/miolamio/agent-skills), [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru) и [ilyautov/humanizer-ru](https://github.com/ilyautov/humanizer-ru). Это отдельная сборка: исходные авторы не заявлены её проверяющими и не должны отвечать за наши изменения.

Справочники переработаны вокруг глубины поручения, фактов и авторского голоса. Убраны обязательное число редакторских проходов, квоты на знаки и ритм, автоматическое назначение оценок и добавление конкретики без основания. Нормативное тире, пассив и «не только… но и» не считаются ошибками сами по себе.

Первоначальная локальная редакция — 7 сентября 2026 года. Первая публичная упаковка — 20 октября 2026 года. Подготовка репозитория добавила установку, полные лицензии, проверенные ссылки и переносимые формулировки; личные пути и сведения о конфигурации компьютера исключены.

Полные тексты книг, словарей и статей в пакет не входят. Ссылки на языковые справочники не означают, что их авторы проверили или одобрили этот навык.
