# ru-text — вычитка и редактура русского текста

Навык для вычитки и редактуры русского текста в Кодексе, Claude Code и других агентах, поддерживающих папку с `SKILL.md`.

Навык помогает исправлять ошибки и делать изложение понятнее. Объём правки зависит от просьбы: от одной опечатки до редактуры всего текста. Инструкции требуют сохранять факты, оговорки и голос автора. Хороший текст можно оставить без изменений.

Эта редакция объединяет материалы четырёх открытых проектов. Лицензия — [MIT](LICENSE). Авторы, исходные проекты и сведения о переработке перечислены в [уведомлениях](THIRD_PARTY_NOTICES.md).

## Что умеет

- Исправлять конкретную опечатку без переписывания соседних предложений.
- Исправлять орфографические, грамматические и пунктуационные ошибки.
- Делать изложение яснее, уточнять связи между мыслями и подбирать слова в пределах поручения.
- Убирать пустые и неестественные обороты с сохранением авторской манеры.
- Работать с письмами, статьями, документацией и текстами интерфейса.
- Оценивать качество по пяти направлениям, когда пользователь прямо просит оценку.

Обычное «проверь текст» означает вычитку. Такая просьба сама по себе не разрешает выставлять баллы, менять стиль или сохранять правки в файлах. При редактировании агент должен сохранять числа, имена, цитаты, ссылки, отрицания, степень уверенности и обещания.

Навык не определяет машинное авторство и не обещает обход детекторов. Сам русский язык сообщения не запускает полную редактуру ответа.

## Установка

Через каталог Agent Skills, если у тебя установлен Node.js:

```sh
npx skills add varvbudi-netizen/ru-text --skill ru-text
```

Либо скопируй репозиторий целиком в свободную папку навыка. Примеры для Windows и PowerShell:

Кодекс:

```powershell
git clone https://github.com/varvbudi-netizen/ru-text.git "$env:USERPROFILE\.codex\skills\ru-text"
```

Claude Code:

```powershell
git clone https://github.com/varvbudi-netizen/ru-text.git "$env:USERPROFILE\.claude\skills\ru-text"
```

В других системах обычные пути установки — `~/.codex/skills/ru-text` и `~/.claude/skills/ru-text`. При ручном копировании сохрани `references/`, `licenses/`, `LICENSE` и `THIRD_PARTY_NOTICES.md`: это необходимые справочники и уведомления об авторстве. После установки обнови список навыков или начни новый сеанс агента.

## Как пользоваться

```text
Используй ru-text. Исправь только ошибки, сохрани мой тон:
[текст]
```

```text
Используй ru-text. Сделай письмо понятнее и короче.
Не меняй факты, сроки и степень вежливости:
[текст]
```

```text
Используй ru-text. Покажи проблемы и предложи правки,
но не изменяй файл.
```

Список режимов и границ — в [SKILL.md](SKILL.md). Справочники загружаются по задаче: одна опечатка не требует чтения всего набора.

## Происхождение и изменения

Использованы [talkstream/ru-text](https://github.com/talkstream/ru-text), [miolamio/agent-skills](https://github.com/miolamio/agent-skills), [smixs/humanizer-ru](https://github.com/smixs/humanizer-ru) и [ilyautov/humanizer-ru](https://github.com/ilyautov/humanizer-ru). Это отдельная переработка. Указание исходных авторов не означает, что они проверили или одобрили эту редакцию.

В справочниках уточнено, как выбирать объём правки, сохранять факты и авторскую манеру. Убраны требования к числу редакторских проходов, количеству знаков и ритму, автоматическое выставление оценок и добавление конкретики без основания. Тире, страдательный залог и конструкция «не только… но и» не считаются ошибками сами по себе.

Локальная редакция создана 7 сентября 2026 года, впервые опубликована — 20 октября 2026 года. Для публикации добавлены инструкция установки, полные тексты лицензий и проверенные ссылки. Из документации убраны личные пути и сведения о настройках компьютера.

Полные тексты книг, словарей и статей в пакет не входят. Ссылки на языковые справочники не означают, что их авторы проверили или одобрили этот навык.
