# Примеры с границами правки

Все сведения для вариантов «после» содержатся в варианте «до». Это учебные пары; новые цифры, источники и действия не подставляются. Сценарии контрольного применения навыка хранятся отдельно от рабочего справочника.

## Один исходник — разная глубина

Исходник:

> В настоящее время команда осущестляет проверку данных. Возможно, отчёт будет готов к пятнице.

**«Исправь опечатку».**

> В настоящее время команда осуществляет проверку данных. Возможно, отчёт будет готов к пятнице.

Изменено только ошибочное слово. Канцелярская форма и прогноз не повод расширять просьбу.

**«Отредактируй, сделай яснее».**

> Сейчас команда проверяет данные. Возможно, отчёт будет готов к пятнице.

Упрощено изложение. «Сейчас» сохраняет временное ограничение, «возможно» — неопределённость срока. Нельзя написать «Команда подготовит отчёт в пятницу».

**«Оцени, ничего не переписывай».**

Укажи опечатку и тяжёлую конструкцию, отдельно оцени качество по критериям. Исходник не изменяется. Баллы не следуют из предыдущих двух просьб.

## Ошибки языка

| Просьба и исходник | Допустимый результат | Что проверяется |
|---|---|---|
| Вычитать: «Согласно распоряжения доступ закрыт» | «Согласно распоряжению доступ закрыт» | Управление, без раскрытия неизвестного исполнителя |
| Вычитать: «Перечень замечаний опубликованы» | «Перечень замечаний опубликован» | Главное слово группы |
| Вычитать: «Мы хотим организовать и руководить работой» | «Мы хотим организовать работу и руководить ею» | Разное управление при сохранении намерения |
| Вычитать: «Он стараеться подключится» | «Он старается подключиться» | Личная форма и инфинитив |
| Вычитать: «В течении месяца мы проверим данные» | «В течение месяца мы проверим данные» | Период времени, не изменение течения |
| Вычитать: «Что бы успеть, начнём сегодня» | «Чтобы успеть, начнём сегодня» | Союз цели |
| Вычитать: «Не смотря на дождь, встреча состоялась» | «Несмотря на дождь, встреча состоялась» | Уступка, не буквальное смотрение |
| Вычитать: «Прочитав письмо, у меня возник вопрос» | «После чтения письма у меня возник вопрос» | Связь добавочного действия; род автора не придуман |
| Только запятые: «Возможно ответ уже готов» | «Возможно, ответ уже готов» | Слово вероятности сохранено |
| Только запятые: «Однако проверив цифры мы передумали» | «Однако, проверив цифры, мы передумали» | Запятая относится к обороту, а не к союзу |

## Правильно оставить

| Исходник при обычной вычитке | Почему не исправлять |
|---|---|
| Большинство слушателей задали вопросы | Возможно согласование по смыслу |
| Готовя выступление, нужно проверить даты | Исполнитель совпадает у деепричастия и инфинитива |
| Открыв файл, проверьте подпись | Исполнитель задан повелительной формой |
| В течении реки заметны завихрения | «Течение» — существительное |
| Что бы ни произошло, я позвоню | Местоимение и частица, не союз цели |
| Работаем так же, как раньше | Способ действия и сравнение |
| Эскадра шла в виду берега | Значение видимости, не причина |
| Посмотрим по окончанию слова | Признак, а не время после события |
| Он отвечал молча | Наречная функция, запятая не требуется |
| Нужно по крайней мере два дня | Количественная нижняя граница |
| Главная задача, которую обсуждали, — уточнить срок | Запятая и тире стоят по своим основаниям |
| Он проверил не только текст, но и подписи | Два объекта, полноценное добавление |
| Отчёт точный и подробный | Два свойства, не механическая синонимия |
| Нам понадобилось минут двадцать | Естественное приблизительное количество |
| Я очень рад, что ты вернулся | Эмоция автора, не неподтверждённая реклама |
| СРОЧНО: позвони мне | Акцент сообщения, не ошибка набора |

## Сокращение без новых фактов

**До:**

> Наш сервис представляет собой комплексное решение для планирования задач и обмена сообщениями между участниками команды.

**После:**

> Наш сервис помогает команде планировать задачи и обмениваться сообщениями.

Нельзя добавить «доски», «за десять минут», «бесплатно до десяти человек»: этих сведений нет.

**До:**

> Отделом осуществляется проверка заявок. О завершении проверки будет сообщено дополнительно.

**После:**

> Отдел проверяет заявки. О завершении проверки сообщат дополнительно.

Исполнитель проверки известен, исполнитель сообщения — нет. Срок сообщения не придуман.

**До:**

> Необходимо осуществлять резервное копирование только после проверки данных.

**После:**

> Необходимо создавать резервные копии только после проверки данных.

Сохранены необходимость, повторяемость и ограничение «только после». Нельзя заменить на «Создайте копию»: изменится объём действия.

**До:**

> Платформа помогает не только экономить время, но и тратить его меньше.

**После:**

> Платформа помогает экономить время.

Убран повтор, числовая экономия не выдумана. Это не правило удалять любые «не только… но и».

## Опасные подмены

| Исходник | Недопустимая «редактура» | Причина |
|---|---|---|
| Около 50 участников | 50 участников | Исчезла приблизительность |
| Более 100 заявок | 100 заявок | Изменилась граница |
| Доля снизилась до 20% | Доля снизилась на 20% | Другая величина изменения |
| Возможно, обновление поможет | Обновление поможет | Прогноз стал обещанием |
| Можно подать заявление онлайн | Подайте заявление онлайн | Возможность стала указанием |
| После обновления возник сбой | Обновление вызвало сбой | Последовательность стала причинностью |
| Результат неоднозначный | Эксперимент провалился | Оценка усилена |
| Приём временно приостановлен | Приём прекращён | Утрачена временность |
| Ирина неоднозначно оценила работу | Ирина сказала: «Работа плохая» | Придумана дословная цитата |
| Эксперты считают, что рынок вырастет | Я считаю, что рынок вырастет | Подменён автор мнения |
| Данные не сохранены | Мы сохранили черновик | Смысл изменён на противоположный |
| Исследуется связь двух факторов | Мы доказали, что один вызывает другой | Придуманы исполнитель, результат и причина |

## Неоднозначность и защищённые фрагменты

**Запрос:** «Исправь опечатку в описании; команду оставь как есть».

**До:** «Команда `tool --name "тест" --rate 0.5` запускает оброботку».

**После:** «Команда `tool --name "тест" --rate 0.5` запускает обработку».

Кавычки, дефисы и точка в числе команды сохранены. То же ограничение относится к ссылке, переменной, коду и идентификатору.

**Запрос:** «Вычитай абзац с дословной цитатой».

**Исходник:** «В источнике написано: „Согласно приказа доступ закрыт“. Автор документа не указан».

Ошибка внутри дословной цитаты не исправляется незаметно. Можно отдельно указать, что в ней ненормативное управление. Если это авторский черновик реплики, а не цитата источника, нужна соответствующая явная задача.

**Запрос:** «Уточни, кто должен отправить документ».

**Исходник:** «Ольга сказала Марине, что она отправит документ».

Контекста недостаточно для выбора исполнителя. Покажи два чтения и уточни, кто отправляет. Стилистическая уверенность редактора не заменяет отсутствующий факт.
