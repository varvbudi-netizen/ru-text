# Происхождение и решения об объединении

## Исходные материалы

Рабочая редакция создана 7 сентября 2026 года из сопоставления четырёх редакторских направлений. Это переработанный справочник, не механическое соединение исходных инструкций.

| Источник | Состояние при переносе | Что использовано |
|---|---|---|
| Плагин `ru-text` | 2.7.0; входы `ru-text`, `ru-check`, `ru-score` | Грамматика, пунктуация, оформление, ясность, 18 дополнений, жанры, пять критериев оценки, контрольные исключения |
| `ru-editor` | 2.1.0; автор в метаданных: Anthony Vdovitchenko @ Automatica | Лексика, канцелярит, повторы, структура, примеры и способы редакторской проверки |
| `humanizer-ru-lite` | 1.2.0, указана MIT | Краткая диагностика шаблонных формулировок и сохранение авторской фактуры |
| Плагин `humanizer-ru` | 3.20.0 | Редакторская часть, каталог из 64 пунктов, защита фактов, терминов и авторского голоса |

Источники, авторы и сохранённые лицензии перечислены в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md). Полные исходные деревья и личные резервные копии не входят в этот репозиторий.

Пакет предоставляет один вход — `ru-text`. Устанавливать исходные плагины для его работы не требуется.

У `nora-gal` уточнена область выбора: литературная редактура, перевод, явный запрос метода Норы Галь. Его содержательные справочники сохранены. У `project-text-clarifier` сохранён обход проекта и уточнено использование общих языковых правил.

## Карта решений

| Группа исходных правил | Решение | Рабочее место |
|---|---|---|
| ru-text: три отдельных входа; ru-editor и humanizer: общее «отредактируй» | Один выбор глубины, четыре режима; локальная опечатка отдельно от полной вычитки | `SKILL.md` |
| ru-check: полный корпус по слову «вычитай» | Проверять весь выбранный текст, но справочники подбирать по содержанию | `SKILL.md` |
| ru-editor: три прохода; humanizer: несколько обязательных проходов | Не фиксировать число итераций; проверять результат и останавливаться по задаче | `SKILL.md` |
| ru-text: типографика во всех ответах | Только нужный объём и носитель; сама русская речь не запускает навык | `SKILL.md`, `typography.md` |
| humanizer: защита чисел, имён и цитат | Расширено на границы, модальность, причину, субъектов, голос и социальное действие | `meaning.md` |
| ru-editor: приблизительные числа заменить точными | Исключено; приблизительность и границы сохраняются | `meaning.md`, `examples.md` |
| Все: конкретика вместо пустых оценок | Сохранено с условием наличия данных; выдуманные сроки и проценты исключены | `editing.md`, `patterns.md` |
| ru-editor: эвфемизм заменить резким фактом | Исключены усиление оценки и правовая переквалификация; уточнение только по данным | `meaning.md`, `editing.md` |
| Все: пассив заменить активом | По известному исполнителю и задаче; статус и поведение системы допустимы | `editing.md`, `genres.md` |
| ru-text: editorial-grammar C/D | Согласование, числительные, имена и регистр сохранены с вариантами нормы | `grammar.md` |
| ru-text: editorial-grammar I | Управление сохранено; закрытый список не ограничивает поиск реальной ошибки | `grammar.md` |
| ru-text: editorial-grammar J | Сохранены исключения с инфинитивом и личными формами; неизвестный деятель не придумывается | `grammar.md` |
| ru-text: editorial-grammar K | Различение написаний по значению; добавлены контрастные правильные случаи | `grammar.md` |
| ru-text, humanizer: вид глагола | Процесс, намерение, попытка и результат защищены; разные виды не запрещены | `grammar.md`, `meaning.md` |
| ru-editor typography: запятая всегда внутри сложного союза | Исключено; членение определяется конструкцией | `punctuation.md` |
| humanizer: «такие как» как ошибочная калька | Исключено; две нормативные схемы | `punctuation.md` |
| ru-text: editorial-punctuation, вводные слова | Переработано через функцию слова, а не постоянное «да/нет» | `punctuation.md` |
| lite/humanizer: запрет тире; ru-text AD-1: квота на тире | Исключено; типографский знак и синтаксис не определяют качество сами по себе | `punctuation.md`, `typography.md` |
| ru-text AD-17: нормативная запятая с тире считается стилистическим дефектом | Исключено; возможное упрощение только из-за реальной трудности чтения | `punctuation.md` |
| Все: обязательные ёлочки, «ё», неразрывные пробелы | Зависимость от носителя и редакционной политики, защита технических фрагментов | `typography.md` |
| ru-text: цифрами все точные числа начиная с десяти | Исключена универсальная граница; жанр и сопоставимость важнее | `typography.md` |
| ru-text: одинаковый формат дат и российских телефонов всюду | Исключена слепая локализация данных и международных форматов | `typography.md` |
| ru-editor/humanizer: антиканцелярит | Сохранён как контекстная редакторская операция | `editing.md` |
| ru-editor: словарь сложных слов | Нет массовой замены; сохранены значение и термины, опасные пары разобраны | `editing.md` |
| ru-editor: требование варьировать повтор; humanizer: запрет карусели синонимов | Принято единообразие терминов; ненужный повтор убирается по смыслу | `editing.md`, `patterns.md` |
| ru-text: списки и параллелизм; humanizer: убрать регулярную структуру | Форма по функции; реальные последовательности и списки сохраняются | `editing.md`, `punctuation.md` |
| AD-2/3/4/6/9/11/16 | Сохранены диагностика повтора, ложной связи и пустых конструкций; убраны квоты и запреты формы | `patterns.md` 1, 6–8, 11–12 |
| AD-5/12; humanizer 47/53/55 | Сохранена проверка смысла и механизма, исключения для терминов и образности | `patterns.md` 5, 14–15 |
| AD-7/10; humanizer 25/41/46/54 | Самопохвала отдельно от вероятности, вежливости, признания и авторского голоса | `meaning.md`, `patterns.md` 9 |
| AD-8/14 | Реплики помощника и неподходящая форма документа; сохранены диалог, интервью, стенограмма | `patterns.md` 10, 16 |
| AD-13 | Неназванный источник — повод уточнить; атрибуция не меняется на «я» | `meaning.md`, `patterns.md` 4 |
| AD-15 | Полезность для читателя; поисковая формулировка не запрещена | `patterns.md` 16 |
| AD-18; info-style B.1/B.2 | Сохранены акценты, признания, частицы; отвергнуто снятие исключений по соседним «ИИ-маркерам» | `meaning.md`, `typography.md`, `genres.md` |
| humanizer 20/23/32/33/36–38/43–48 | Исключены добавление ошибок, редких слов, мнений, обязательных идиом и числовой ритм | `SKILL.md`, `patterns.md` |
| humanizer 49–52/56–58 | Сохранены контекстная проверка рваности, навязанного тона, заголовков и обрыва | `patterns.md`, `grammar.md` |
| humanizer 59–64 | Не перенесены как автоматические требования; литературные решения — по задаче, без новых событий | `genres.md`, граница с `nora-gal` |
| ru-text ux-writing | Сохранены точность подписей, статусов, ошибок и склонения; изменения дизайна и придуманные свойства не перенесены | `genres.md` |
| ru-text business-writing | Сохранены адресат, действие, отказ, уважение; новые сроки, поручения и молчаливое согласие не добавляются | `genres.md` |
| ru-score/scoring: пять измерений | Сохранены пять направлений и веса; балл только по запросу | `scoring.md` |
| scoring: жёсткие потолки за оформление и автоматические ярлыки | Заменены явным описанием критической проблемы; неприменимые критерии исключаются с пересчётом | `scoring.md` |
| humanizer: сканер, статистика, вероятность ИИ, приоритет стиля над грамотностью | Не перенесены; редактура оценивает содержание и язык, не происхождение | `patterns.md`, `scoring.md` |
| Все: примеры с новыми фактами | Заменены парами без расширения содержания; опасные пары показаны как недопустимые | `examples.md` |
| Исходные контрольные случаи | Использованы для поиска исключений; прежние ожидаемые штрафы не считаются истиной | Карта проверки в отчёте объединения |

- [miolamio/agent-skills, ru-editor](https://github.com/miolamio/agent-skills/tree/b2bd8eec125859987418bdc984e977a01b76e930/skills/ru-editor): Anthony Vdovitchenko, [лицензия](../licenses/ru-editor-MIT.txt). Исходное объединение выполнено 7 сентября 2026 года; публичная упаковка подготовлена 20 октября. Даты и версии описывают использованные материалы, а не заявление об их сегодняшней последней версии. Правила переработаны; исходные авторы не заявлены соавторами или проверяющими этой сборки.

Статистические заявления о «машинности», научные проценты из исходных навыков и описания их прошлых прогонов не перенесены как установленные факты. Проверенные нормативные опоры и граница внешней проверки перечислены в [источниках](sources.md).
